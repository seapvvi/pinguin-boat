# Code de conduite

Nous voulons une communauté ouverte et respectueuse.

## Attendu

- Respect envers chacun, quelles que soient ses origines ou son niveau.
- Critiques constructives, centrées sur le code et non sur la personne.

## Inacceptable

- Harcèlement, insultes, discrimination.
- Publication d'informations privées d'autrui.

## Application

Les mainteneurs peuvent modérer, avertir ou bannir. Signalement : via l'onglet Security du dépôt ou le serveur de support.
