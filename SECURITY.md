# Politique de sécurité

## Signaler une vulnérabilité

Ne publiez pas de faille dans une issue publique. Utilisez l'onglet **Security → Report a vulnerability** du dépôt (signalement privé GitHub).

Indiquez la description, les étapes de reproduction et l'impact. Nous répondons dès que possible.

## Secrets

Si vous trouvez un token Discord, un secret OAuth ou un `GITHUB_TOKEN` exposé, signalez-le en privé. Il sera régénéré immédiatement.

## Versions supportées

Le projet est en alpha : seule la branche `master` reçoit des correctifs.
